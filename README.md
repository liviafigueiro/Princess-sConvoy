# Princess's Convoy

Projeto desenvolvido em Python utilizando a biblioteca **Pygame**, com foco na criação de um jogo 2D.


## Sobre o projeto

Este jogo foi desenvolvido como parte do meu processo de aprendizado na disciplina de Linguagem de Programação Aplicada, com foco em aplicar conceitos de lógica, estruturação de código e desenvolvimento de jogos simples em 2D.

Durante o desenvolvimento, tive a oportunidade de praticar e consolidar conhecimentos em Python por meio de um projeto mais prático e visual.


## Aprendizados

Este projeto contribuiu para o desenvolvimento de habilidades como:

- Lógica de programação aplicada em um contexto real
- Organização e estruturação de código
- Manipulação de eventos e elementos em jogos 2D com Pygame
- Resolução de problemas durante o desenvolvimento
- Interpretação de erros e depuração
- Aprendizado contínuo através de pesquisa e documentação


## Tecnologias utilizadas

- Python  
- Pygame
